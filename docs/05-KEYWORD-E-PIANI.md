## 2. Roadmap 90 giorni
- **1–7**: pubblica; controlla le 5 URL; aggiungi proprietà e sitemap; ispeziona home e 2 guide. *Obiettivo*: sitemap letta, home “URL su Google” oppure motivo chiaro.
- **8–30**: controlla “Pagine”; correggi eventuali esclusioni; non modificare le pagine ogni giorno. *Obiettivo*: ≥5 URL indicizzate, prime impression.
- **31–60**: leggi le query reali; rafforza le guide sulle query con impression e CTR basso; verifica le tabelle e compila la data; decidi la strategia IT/EN (URL separati con hreflang). Scrivi 1–2 guide nuove solo con dati verificati.
- **61–90**: confronta clic/impression con i giorni 31–60; guarda i concorrenti nelle query reali; valuta dominio e monetizzazione *solo* se c'è traffico stabile. Se le impression restano ~0, rivedi contenuti e link esterni (condivisioni in community) prima di spendere.

## 3. Monetizzazione (non attivata)
- **Pubblicità (es. AdSense)**: l'approvazione non è garantita; richiede contenuti originali sufficienti, pagine legali, di solito un dominio proprio; una SPA con pochi testi è debole. Prima: più guide utili, traffico organico costante, informativa/consenso cookie conformi (utenti UE).
- **FREE/PRO** (ipotesi): FREE com'è oggi; PRO per simulazioni avanzate/senza pubblicità. Richiede pagamenti, account e privacy: non ora.
- **Supporto volontario**: esiste già il link Buy Me a Coffee; opzione più leggera.
- **Affiliazioni**: nessun programma verificato, non valutare.
- **Modello economico**: variabili = utenti attivi, sessioni, pagine/sessione, impression, RPM reale, costi (dominio, tempo), tasse da verificare con un commercialista. Ricavi lordi ≠ netti ≠ profitto. Nessun valore è stimato qui perché non esistono dati.

## 4. Dominio (non acquistare ora)
Valuta quando ci sono dati in Search Console e un motivo concreto. Migrazione futura: acquista → configura DNS verso GitHub Pages + HTTPS → aggiorna canonical, sitemap, JSON-LD, `og:url` e link → ricrea la proprietà in Search Console → usa lo strumento di cambio indirizzo (GitHub Pages non offre redirect 301 dal vecchio URL: tieni il vecchio sito con canonical verso il nuovo) → ricontrolla.
